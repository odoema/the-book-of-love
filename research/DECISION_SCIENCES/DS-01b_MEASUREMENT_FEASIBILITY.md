# DS-01b — Measurement Feasibility

**Status:** OPEN

## Classification

- **A:** field measurable
- **B:** laboratory measurable
- **C:** special-event measurable
- **D:** latent/inferred

| Construct | Preliminary class | Main route |
|---|---|---|
| A_t | A | decision-rights audit and logs |
| D_t | C + supporting field indicators | interruptions, drills, failures |
| H_t | B/C | controlled tasks and stress tests |
| E_t | A/C/D depending on component | switching/substitution tests and inference |

## Strategy

1. **Natural experiments:** outages, maintenance, deliberate interruption.
2. **Cross-sectional variation:** teams/institutions at different adoption levels.
3. **Longitudinal variation:** changes over time where records permit.
4. **Distributional analysis:** examine variance and critical subgroups, not only means.

The binding measurement problems are H_t and E_t. If a construct is latent, state indicators and inference assumptions explicitly.

**Measurement-before-model rule:** no additional model should be treated as empirically motivated until measurement feasibility and uncertainty are specified.
