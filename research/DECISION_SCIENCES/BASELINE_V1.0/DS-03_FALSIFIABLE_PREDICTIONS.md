# DS-03 Falsifiable Predictions

## P1 — Multiple states
For sufficiently nonlinear cooperative response, parameter regions should exist in which more than one stable state is available.

## P2 — History dependence
Within such regions, materially different initial conditions should produce different long-run states.

## P3 — Intervention non-equivalence
Reinforcement reduction, exit-cost reduction, and replacement-capacity increases should produce distinguishable recovery patterns under controlled experiments.

## P4 — Basin dependence
A temporary intervention should not necessarily permanently change the long-run state when the underlying parameters are restored.

## P5 — Hysteresis criterion
A classical hysteresis claim requires demonstrable different switching thresholds under increasing and decreasing parameter sweeps.

## P6 — Governance reversal
A governance process can declare reversal while failing the RTSP if decision rights, meaningful exit, alternatives, or dependency remain effectively controlled by the former authority.

## P7 — External verification
Independent assessors should be able to classify whether RTSP conditions have been met using predefined evidence rather than relying on the authority-holder's declaration.

## P8 — Robustness
If the persistence mechanism is substantive rather than a numerical artefact, qualitatively similar path dependence should survive reasonable changes in numerical method and model specification.

## Falsification principle

A negative result is a valid research result. The project must not modify definitions after observing a result solely to preserve the preferred hypothesis.
